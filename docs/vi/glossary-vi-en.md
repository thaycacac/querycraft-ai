# Bảng thuật ngữ Việt - Anh

| Tiếng Anh | Tiếng Việt / giải thích |
|---|---|
| Text-to-SQL | Chuyển ngôn ngữ tự nhiên thành SQL |
| Semantic parsing | Phân tích ngữ nghĩa: câu tự nhiên → biểu diễn hình thức thực thi được |
| Schema linking | Liên kết từ trong câu hỏi với bảng/cột |
| Semantic layer / metric layer | Tầng ngữ nghĩa/metric: định nghĩa nghiệp vụ dùng chung |
| Agentic workflow | Quy trình nhiều bước, LLM dùng công cụ và lặp có phản hồi |
| Self-correction | Tự sửa lỗi dựa trên phản hồi thực thi |
| Clarification | Hỏi lại để làm rõ |
| Ambiguity | Sự mơ hồ |
| Execution Accuracy (EX) | Độ chính xác theo kết quả thực thi |
| Exact Match (EM) | Khớp chính xác cấu trúc SQL |
| Test-suite accuracy | EX trên nhiều DB biến đổi để loại trùng hợp |
| VES | Valid Efficiency Score (BIRD) |
| Ablation | Thí nghiệm gỡ/thêm từng thành phần để đo đóng góp |
| Baseline | Hệ thống cơ sở để so sánh |
| Zero-shot / few-shot | Không/có vài ví dụ trong prompt |
| In-context learning | Học từ ví dụ ngay trong prompt |
| Chain-of-thought | Suy luận từng bước |
| Self-consistency / majority voting | Sinh nhiều lời giải, chọn đáp án phổ biến |
| Hallucination | Mô hình "bịa" nội dung |
| Tokenization | Tách token |
| Embedding | Vector biểu diễn |
| BM25 | Hàm xếp hạng dựa trên tần suất từ và IDF |
| Fine-tuning / SFT | Huấn luyện tinh chỉnh có giám sát |
| Reinforcement learning (RL) | Học tăng cường |
| Distillation | Chưng cất tri thức từ model lớn sang nhỏ |
| Nested / heterogeneous schema | Schema lồng nhau / không đồng nhất |
| UNNEST | Mở mảng thành nhiều dòng |
| Event | Sự kiện hành vi (mở app, mua hàng...) |
| DAU / MAU | Người dùng hoạt động theo ngày/tháng |
| ARPPU | Doanh thu trung bình trên mỗi người dùng trả phí |
| AOV | Giá trị đơn hàng trung bình |
| Retention D1 | Tỷ lệ quay lại sau 1 ngày |
| Conversion rate | Tỷ lệ chuyển đổi |
| Cart abandonment | Bỏ giỏ hàng |
| Bootstrap CI | Khoảng tin cậy bằng lấy mẫu lại |
| McNemar test | Kiểm định cho hai phân loại trên cùng tập mẫu |
| Data contamination | Rò rỉ dữ liệu benchmark vào dữ liệu huấn luyện |
| Threats to validity | Các mối đe dọa tính hợp lệ của kết luận |
