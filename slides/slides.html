1. Bài toán

  • Dữ liệu tracking (app, game, e-commerce): event có tham số lồng nhau (event_params, items), schema không đồng nhất
  • Câu hỏi thực tế: "DAU hôm qua?", "ARPPU tháng 2?", "tỷ lệ bỏ giỏ hàng?"
  • Text-to-SQL thông thường sai ở ba chỗ:

Ba điểm khó

  • Mơ hồ: "doanh thu" = bán hàng, theo món, hay quảng cáo?
  • Khái niệm nghiệp vụ không có trong schema (DAU, ARPPU)
  • Sai im lặng: SQL chạy ra số nhưng sai định nghĩa

1. Mục tiêu, phạm vi, giả thuyết

Mục tiêu

  • Agent LLM + semantic layer: tự ánh xạ schema, resolve metric, sinh SQL chạy được, hỏi lại khi mơ hồ (ý tưởng như Metabot)
  • Benchmark riêng cho event lồng nhau và ablation có kiểm định thống kê

Phạm vi và giả định

  • 1 DB DuckDB tổng hợp, chỉ đọc, hỏi 1 lượt, tiếng Việt và Anh
  • Làm một mình, model chạy local

Giả thuyết

  • H1 agentic (linking, thực thi, tự sửa) tốt hơn prompt đơn
  • H2 semantic layer tăng độ chính xác với metric nghiệp vụ và schema lồng
  • H3 model local nhỏ + semantic layer tiệm cận model API lớn

4. Phương pháp đánh giá

Metric

  • Execution Accuracy (EX): so kết quả thực thi (cho phép hoán vị cột)
  • Clarification P/R/F1 cho câu mơ hồ
  • Valid-SQL rate, độ trễ, token

Thống kê và thiết kế

  • McNemar exact (cùng tập câu), bootstrap 95% CI
  • Ablation tích lũy và từng thành phần riêng lẻ
  • Tập "họ câu chưa thấy" để loại rò rỉ few-shot
  • Spider/BIRD: mẫu 200 câu cố định

6. EventSQL-Bench

Dữ liệu

  • DuckDB, seed 7: 1.500 user, 59 ngày
  • Bảng events với event_params, items lồng nhau
  • Funnel view → cart → checkout → purchase

Câu hỏi: 162 câu

  • L1 phẳng · L2 lồng nhau · L3 metric · L4 join/cohort
  • 37 few-shot pool; 125 test (108 trả lời được, 17 mơ hồ)
  • 3 họ câu giữ ngoài kho few-shot (12 câu)
  • 20 câu paraphrase ngoài từ điển

9. Hạn chế

  • SQL vàng và YAML do cùng tác giả viết → mức tăng của semantic layer có thể lạc quan
  • Few-shot cùng họ rò rỉ khuôn mẫu; nhóm chưa thấy n = 12, paraphrase n = 20
  • Một DB tổng hợp; EX không phải test-suite; Spider/BIRD có thể bị contamination
  • Ba seed giống hệt nhau (temperature 0) → không đo được phương sai
  • Chưa chạy: model API, Spider 2.0, Dr.Spider

Hướng phát triển

  • Chạy model API; người thứ hai viết SQL vàng; test-suite accuracy
  • Schema linker bằng embedding; majority voting; fine-tune/RL model nhỏ
  • Kiểm chứng trên GA4/Spider 2.0; hội thoại nhiều lượt
